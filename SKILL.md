# horizen-attest

horizen-attest generates and verifies ZK attestations inside the Horizen L3 stack. Proofs are quality-scored by the negentropy engine and admission-gated by zenkinetic's ZEN staking rules.

## When to use

Building verifiable-credential or attestation flows on Horizen Base L3.

## Install

```
cargo add horizen-attest
```
